Top drawer: what the tool does

analyze-network-protocol-fuzzer is a command-line tool that fuzzes network protocols by generating and sending malformed packets to a target service to identify potential vulnerabilities or crashes. It sends random, mutated, or oversized random byte packets to a named target, and its heading line places it under data analysis and reporting.

Printed on this drawer card itself: the README names no protocols that the tool covers, and this drawer adds no claim about which protocols they might be.

Third drawer: the controls, laid out as pinned specimens

-h: Show help message and exit

-t: Target IP address or hostname.

-p: Target port number.

-n: Number of packets to send. Default: 100

-s: Size of each packet in bytes. Default: 100

-f: Fuzzing type: random, mutate, or overflow. Default: random

-l: Path to the log file. If not specified, logs will be printed to the console.
